# Вклад

1. Не добавляйте секреты, live-логи, IP пользователей и backup-архивы.
2. Для shell-изменений запускайте `bash -n scripts/*.sh`.
3. Документируйте новые переменные в `.env.example`.
4. Сохраняйте разделение read-only и write-операций.
5. Не добавляйте автоматический production deploy в GitHub Actions.

Pull request должен описывать затронутые сервисы, способ отката и результат проверок.
