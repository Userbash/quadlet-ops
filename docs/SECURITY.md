# Безопасность

- Не коммитьте `.env`, ключи, сертификаты, токены, базы, логи и архивы.
- Не добавляйте реальные IP и access-логи в публичные issues или pull requests.
- Используйте отдельный SSH-ключ с ограниченным пользователем и `sudo`-политикой.
- `DEPLOY_CONFIRM=YES` нужен для restore и activate.
- Bootstrap не меняет SSH, DNS, TLS и firewall без отдельной реализации.
- Перед публикацией запускайте поиск секретов из GitHub Actions.

Публичный репозиторий содержит только шаблоны и документацию. Production-секреты храните в менеджере секретов или rootless secret-файлах на сервере.
