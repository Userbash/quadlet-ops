# Подготовка публичного проекта

## Цель

Подготовить репозиторий к публикации на GitHub без live-секретов и архивов данных.

## Решения

- Оставить Bash и fish как основной стек.
- Разделить чтение (`backup`, `validate`) и запись (`restore`, `activate`).
- Требовать `DEPLOY_CONFIRM=YES` для записи.
- Использовать `.env.example` как публичный контракт переменных.
- Не включать backup-архивы в Git.

## Ограничения

Bootstrap ориентирован на Debian/Ubuntu. Установка TLS, DNS, SSH-ключей и application data остаётся отдельной операционной процедурой.
